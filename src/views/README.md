# Dossier `src/views/`

Contient les différents écrans du jeu, idéalement gérés par le système de vues (Views) d'Arcade.

- **game_view.py** : L'écran principal du jeu (le labyrinthe plongé dans le noir).
- **game_over_view.py** : L'écran de défaite (si la créature nous dévore ou selon le mode de jeu sélectionné).
- **level_select.py** : Sélection de l'étage de la tour.
- **main_menu.py** : Écran d'accueil avec le lore, le choix du mode de jeu et la musique d'ambiance.
- **victory_view.py** : Écran de victoire (sommet de la tour atteint) avec l'affichage des statistiques de la partie.
