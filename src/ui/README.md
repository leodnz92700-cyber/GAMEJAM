# Dossier `src/ui/`

Contient tous les éléments d'interface utilisateur (HUD, boutons, fenêtres de dialogue) qui seront affichés par les vues (`src/views/`).

- **dialog_box.py** : Affichage du lore et des textes PNJ.
- **hud.py** : Affichage de l'inventaire.
- **menu_components.py** : Boutons et sélecteurs pour les menus.
