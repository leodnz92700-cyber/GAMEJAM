# assets/audio/

Tous les sons et musiques du jeu.

- Musique de fond : une piste flippante pour le menu, une (ou
  plusieurs, selon l'étage) pour la boucle en jeu.
- Bruitages de gameplay : pas du joueur, porte qui grince, ramassage
  d'objet, torche qu'on plante, mort du joueur.
- Grognement(s) : le signal sonore qui annonce que le timer caché
  vient de s'écouler et que l'ennemi se réveille. Prévoir 2-3
  variantes pour éviter que ça sonne toujours pareil.
- Son de la porte spéciale : distinct des autres portes, pour que le
  joueur associe inconsciemment ce bruit précis au danger, sans texte
  explicatif.
- Ambiance/silence : éventuellement une nappe sonore discrète et
  continue qui peut légèrement s'intensifier à l'approche du réveil,
  si vous voulez un indice subtil sans jamais recréer un compte à
  rebours audible évident.

Format court et léger recommandé (ogg/wav compressé) pour les
bruitages ponctuels, garder les musiques longues en format compressé
également pour ne pas alourdir le build de la Game Jam.
